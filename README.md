# ABC Race

A simple alphabet speed game for students.

## How to play
1. Choose lowercase, uppercase, or random.
2. Click **Start!**
3. Click the letters in alphabetical order.
4. The timer stops after Z.
5. Best time is saved in the browser.

## Upload to GitHub Pages

### Option A — Put it in its own folder
Upload the folder `abc-race` into your website repository.

Example:

```
your-repository/
├── index.html
├── style.css
├── script.js
└── abc-race/
    ├── index.html
    ├── style.css
    └── script.js
```

Then the game URL will be similar to:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/abc-race/`

### Link it from your main website

```html
<a href="abc-race/">ABC Race</a>
```

No server or database is required.
